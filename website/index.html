給它資料，它真的去算Give it data and it really computes

附上 CSV 或 Excel，它在沙箱裡實際執行程式：讀完整資料、分析、繪圖。報告裡的數字來自執行結果，另附可以重跑的 .py。Attach a CSV or Excel file and it runs real code in a sandbox: reads all the data, analyses, plots. The numbers in the report come from that run, with a .py you can rerun.

寫完，再請別人挑錯Then someone else checks it

報告完成後，另開一次獨立呼叫來審查，Auto 模式由不同廠商的模型負責。它對照數字、表格與程式結果，另存一份審查清單，只列問題，不改你的報告。Once a report is done, a separate, independent call reviews it; in Auto mode that reviewer is a model from a different vendor. It compares the figures, tables and code output and saves a review list. It reports problems; it doesn’t touch your report.
