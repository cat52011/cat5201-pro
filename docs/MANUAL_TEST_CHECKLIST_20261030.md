## 1. 真的 API 會不會接受 ★★★　風險最高

這幾處我照文件改了送出的設定，但只有實際送出才知道對不對。
**每一項的判斷方式都一樣**：失敗不可怕，**沒講才可怕**——系統要嘛成功，要嘛在答案最上方說「已改用其他模型」。

### 1-1　手動 Claude 的搜尋研究
節點設**手動**、模型選 **Claude Sonnet 5.5**，貼：
```
研究台積電最近一季財報與近期股價表現，列出關鍵數字與可信來源
```
- ☐ 有答案
- ☐ 決策窗「參與」欄：搜尋研究那一行寫 **Claude Sonnet 5.5 經 Perplexity（搜尋研究）**——這代表 Perplexity 接受了 Claude 做搜尋
- ☐ **或者**答案最上方出現「⚠️ 已改用其他模型：你選的 Claude Sonnet 5.5 在「搜尋研究」這一步執行失敗……改由 GPT-5.6 Sol 完成」——這代表 Perplexity 不支援 Claude 搜尋，系統照規則換了並告知
- ☐ 兩種都沒有、卻出現 GPT 參與 → **這是 bug，截圖給我**

> 這一題的結果決定之後的說法：Perplexity 文件沒寫哪些型號支援搜尋工具，跑一次就知道了。

### 1-2　Opus 5.5 的小呼叫（以前一定 400）
手動、選 **Claude Opus 5.5**，問一句短的：
```
用一句話說明什麼是本益比
```
- ☐ 有答案，**答案最上方沒有**「已改用其他模型」
- ☐ 「參與」欄的**輸出意圖判斷**也是 Claude Opus 5.5（以前這一步送出 Opus 5.5 不接受的設定，會失敗後被默默換掉）

### 1-3　Sonnet 5.5 的小呼叫
手動、選 **Claude Sonnet 5.5**，同一句。
- ☐ 有答案，沒有「已改用其他模型」
- ☐ 「參與」欄全部是 Claude Sonnet 5.5

### 1-4　Gemini 不能搜尋時要講
手動、選 **Gemini 3.5 Flash**，貼 1-1 那一題。
- ☐ 答案最上方有「⚠️ 已改用其他模型：你選的 Gemini 3.5 Flash 在「搜尋研究」這一步無法在搜尋服務上執行，系統改由 GPT-5.6 Sol 完成」
- ☐ 主回覆仍是 Gemini 3.5 Flash

## 3. 協作模式 ★★★　新功能，畫面我沒看過

任一節點右鍵 →「**協作模型…**」，勾 **GPT-5.6 Sol** 與 **Claude Opus 5.5** → 確定。
- ☐ 選擇框正常顯示，最多只能勾 4 個；只勾 1 個時有提示
- ☐ 確定後右鍵選單變成「**協作模型…（2 個）**」
- ☐ 滑鼠移到模型選單上，提示寫「協作模式：GPT-5.6 Sol、Claude Opus 5.5 一起回答」

貼：
```
現在適合定期定額還是單筆進場？請給出你的判斷與理由
```
- ☐ 執行中的提示依序出現「……正在各自回答」→「……正在看彼此的回答」
- ☐ 答案有三段：**各模型的回答 → 交叉檢視 → 共識與分歧**
- ☐ 分歧那段標明是誰說的，最後一行是「分歧怎麼取捨由你決定」
- ☐ 答案裡**沒有**露出 ```json 區塊
- ☐ 決策窗狀態顯示「**協作**」；「參與」欄**只有**這兩個模型（沒有「模型自動選擇」的 GPT 呼叫）
- ☐ **存檔 → 關掉 App → 重開**：右鍵仍是「協作模型…（2 個）」
- ☐ 右鍵 →「協作模型…」→「**關閉協作**」→ 回到一般模式

> 費用約為單一模型的四倍（兩個模型 × 兩輪）。

## 4. 可追溯性 ★★

### 4-1　各步驟收到的內容
用第 1-1 題跑完的那個節點，打開決策窗。
- ☐ 有一行「📥 各步驟收到的內容：N 步，每一步都完整包含原始要求」
- ☐ 每一步列出用途、模型、字數、✓／✗、一串 12 碼雜湊
- ☐ 最後一行「完整內容：…\_steplog\….txt」——**打開那個檔案**，裡面每一步都有全文，雜湊與決策窗一致

### 4-2　匯流節點對等
建三個節點，A、B 接到 C（流動連線，藍色虛線）。

節點 A（手動、GPT-5.6 Sol）：
```
用三點說明定期定額的優點，每點一句話
```
節點 B（手動、Claude Sonnet 5.5）：
```
用三點說明單筆進場的優點，每點一句話
```
節點 C（手動、GPT-5.6 Sol），輸入框照打（`{{input}}` 要原樣保留）：
```
比較以下兩份回答，列出彼此矛盾的地方，兩邊的說法都要寫出來：{{input}}
```
先跑 A、再跑 B；C 會在兩個上游都完成後自動開始。
- ☐ 執行 C 後，log 有「匯流 2 個上游，全部完整放進輸入」
- ☐ 打開 C 的 _steplog 檔：**A 與 B 的回答都完整出現**，標成「上游 1／2」「上游 2／2」

### 4-3　手動 GPT 不再顯示 Perplexity Sonar
手動 GPT-5.6 Sol 跑 1-1 那一題。
- ☐ 決策窗「模型」欄**只有 GPT-5.6 Sol**（以前會多出 Perplexity Sonar）
- ☐ 「參與」欄搜尋那一行寫 **GPT-5.6 Sol 經 Perplexity（搜尋研究）**
