## 4. 匯流：第二層要自動執行 ★★★

上一輪 A→B、A→C、B→D、C→D 四條全藍，A/B/C 都跑完了，**D 永遠空白**，而且沒有任何訊息。

照 `FULL` 清單 C-4 的四段提示接出菱形（從 C 的小圓點拖到 D 上放開），四條線全部右鍵改藍。

- ☐ 從 A 執行 → B、C 跑完後 **D 自己開始跑** ★★★
- ☐ D 的輸入裡 B 和 C 的結果**都在**
- ☐ D 只執行一次
- ☐ 如果 D 曾經停住，log 會寫 `收尾補跑：「把上面兩份影響分析合併…」的上游都完成了，但沒有人叫它`
      （看到這行代表安全網救了它——請把那一段 log 給我，主因還沒找到）
- ☐ 等待時 log 寫得出在等誰：`「…」在等上游：…`
- ☐ 讓 B 失敗（清空提示）→ D 不執行，也不會卡在琥珀色等待中

分兩次手動跑也要成立：
- ☐ 只把 B→D、C→D 改藍（A→B、A→C 留灰），**單獨跑 B** → D 不動
- ☐ **再單獨跑 C** → D 自己開始跑
