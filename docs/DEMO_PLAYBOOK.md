# cat5201 — Demo Playbook（§14 展示劇本）
**更新：** 2026-06-20

這份是「拿給老師／評審看」的固定展示腳本。每個 Demo 都有：精確輸入、會跑的管線、預期產出、講解重點、預估成本。
照順序跑即可完整展示產品的五大能力（研究 / 文件 / 簡報 / 圖片 / 附件）+ 防禦機制。

> 前置：在「設定 → API」分頁填好金鑰（或設環境變數），四家擇一即可起跑；要全展示則四家都填。
> 建議在「個人化」開 Auto 模式，讓決策窗顯示自動選模與成本保護。

---

## Demo 1 — 股票分析（即時研究管線）

- **證明：** 即時聯網研究 + 來源查證 + 成本透明。
- **輸入：**
  > 分析台積電（TSM）與美光（MU）的短期投資前景，列出近期關鍵財報數字與主要風險。
- **管線：** research-first（Perplexity Sonar）→ verified_facts → 主合成（general-agent）。
- **預期產出：** 文字分析 + Workspace 出現「已驗證事實」卡片（來源標題／網址／權威度／引用類型）。
- **講解重點：**
  - 決策窗「執行摘要」白話卡：模式 / 任務 / 記憶 / 產出 / 結果。
  - 財經即時任務「本次略過記憶」——避免拿舊資料誤導。
  - Auto 成本保護：不會自動用最貴的 Opus / Deep Research。
  - 決策窗顯示「實際 N tokens」與估算成本。
- **預估成本：** 約 1 次 Sonar 搜尋 + 1 次合成，US$0.01–0.05 等級。

## Demo 2 — 學習計畫 PDF（文件生成）

- **證明：** 檔案生成管線、繁中 PDF 不亂碼。
- **輸入：**
  > 幫我規劃一份三個月的韓語學習計畫，分初級、中級、目標三個階段，最後輸出成 PDF 報告。
- **管線：** general → 報告草稿 → PdfReportBuilder（QuestPDF，Microsoft JhengHei 嵌入）。
- **預期產出：** `_generated/韓語學習計畫_*.pdf`，Workspace artifact 狀態「已匯出」。
- **講解重點：**
  - 點 Workspace 檔案 chip 直接用系統預設程式開啟。
  - 繁體中文字型已嵌入 → 換電腦也不會變方框。
  - artifact 卡片顯示來源 / 時間 / 依賴（報告依賴主合成）。
- **預估成本：** 1 次合成，US$0.01 等級。

## Demo 3 — 研究主題 → 簡報（簡報代理）

- **證明：** 研究→大綱→簡報的多階段管線 + 商業主題。
- **輸入：**
  > 研究 2026 年生成式 AI 在教育的應用趨勢，做成 5 頁簡報。（要附匯入包就加「並附 NotebookLM 匯入包」）
- **管線：** research → PresentationOutlineBuilder（偵測 5 頁）→ PptxBuilder + DeckPdfBuilder。
- **預期產出：** `.pptx` + 對應 `deck.pdf`（商業主題：深藍封面 + 青色強調線 + 頁尾頁碼）；加關鍵字時多一個 `_NotebookLM匯入包.txt`。
- **講解重點：**
  - 頁數偵測（3 / 5 / 10）+ EnforceSlideCount 安全網。
  - 來源頁由 verified_facts 自動生成。
  - 右下角 ↻ 可單張重新生成、保留封面。
  - Gamma 設計引擎為九月升級點（給 GAMMA_API_KEY 才啟用）。
- **預估成本：** 1 研究 + 1 大綱合成，US$0.02–0.05 等級。

## Demo 4 — 圖片生成 → 簡報（多模態）

- **證明：** 圖片生成接進簡報、每張計價的成本提示。
- **輸入：**
  > 做一份關於海洋保育的 3 頁簡報，並幫我生成一張封面圖。
- **管線：** image gen（gpt-image-2）→ 封面圖 → PptxBuilder 嵌入 cover slide。
- **預期產出：** `.pptx`（封面含生成圖）+ `_generated/*.png`。
- **講解重點：**
  - 圖片以「每張」計價，note 顯示「估算 ≈ 1 張圖 · 約 NT$X」。
  - 封面圖只嵌進 deck，不在輸出區重複丟大圖。
  - 圖片狀態 lifecycle：queued → generating → completed。
- **預估成本：** 1 張 1024×1024 高品質約 US$0.17 + 簡報合成。

## Demo 5 — 附件摘要 → Word 報告（附件處理）

- **證明：** 吃附件、摘要、輸出 DOCX。
- **輸入：** 上傳一份 PDF 或長文字附件，搭配：
  > 幫我把這份文件摘要成重點，並輸出成 Word 報告。
- **管線：** attachment → summarize → DocxReportBuilder（OpenXML：標題 / 清單 / 粗體 / 表格）。
- **預期產出：** `_generated/*.docx`。
- **講解重點：**
  - 附件內容進 workspace、被主合成引用。
  - DOCX 可在 Word 開啟、保留標題層級與清單。
- **預估成本：** 1 次摘要合成，視附件長度 US$0.01–0.03。

## Bonus — 防禦機制示範（回答老師「成本 / 穩定性」提問）

- **證明：** API 金鑰多來源 + 自動切換 + 失敗才回報。
- **示範方式：**
  1. 設定 → API：只填一家（例如只填 Gemini），其餘留空。
  2. 隨意下一個任務，手動把模型選成沒填金鑰的那家（例如 GPT）。
  3. 觀察決策窗：主模型因「找不到金鑰」失敗 → 自動沿 fallback 鏈切到 Gemini → 成功，整段切換過程列在決策窗。
  4. 若四家都沒金鑰 → 直接輸出失敗 + 友善原因（「API 金鑰無效或尚未設定」）。
- **講解重點：**
  - 金鑰解析順序：環境變數 → app 內輸入 → 自動切換 → 全失敗才報錯。
  - 觸發自動切換的情況：未偵測到金鑰、額度不足（429）、逾時、伺服器不穩（5xx）、模型不支援該輸入。
  - 金鑰以 Windows DPAPI 加密落地，只有本機帳號能解密，不上傳。
  - 對應老師問的「跟直接用各平台網頁差在哪」：多一層自動分配 + 成本可見 + 容錯。
